# Contributing

The most useful thing you can do is **play it and report what you find**: use the
[bug report form](../../issues/new/choose). A screenshot and where you were in the game make a
report easy to fix.

Suggestions about the translation itself (a line that reads stiffly, a name that feels off, a
joke that didn't land) are welcome too; open an issue and explain what you'd change and why.

Please never attach, link or ask for game images (ISO/BIN/CHD) or BIOS files. This project
distributes only its own work, and anything else will be removed.
